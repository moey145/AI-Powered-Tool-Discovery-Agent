Best Python ORM libraries

Researched from live sources on 2026-11-10.

SQLAlchemy is the best general-purpose choice: it offers both ORM and SQL toolkit features, broad database-dialect support, and is free and open source. Choose Django ORM instead when your project uses Django, or Tortoise ORM when you need an async-native ORM.

SQLAlchemy

SQLAlchemy is a Python SQL toolkit and Object Relational Mapper (ORM) for database access. It provides ORM and Core features, including database connections, schema management, and support for multiple database dialects.

Free · MIT · 12,271 GitHub stars · updated 2026-11-09

Django ORM

Django ORM is the object-relational mapper included with Django. It can also be used in standalone scripts or services after configuring Django settings and calling `django.setup()`.

Free · Open source

Website · Source 1 · Source 2

Peewee

Peewee is a small Python ORM with a flexible query builder for working with SQL databases. It supports SQLite, MySQL, MariaDB, and PostgreSQL, and offers integrations with frameworks including Flask and FastAPI.

Free · MIT · 12,004 GitHub stars · updated 2026-11-10

Website · GitHub · Source 1 · Source 2 · Source 3

Pony ORM

Pony ORM is a Python object-relational mapper that lets developers work with relational database rows as objects. It translates Python generator expressions and lambda-based queries into SQL.

Free · Open source

Website · Source 1 · Source 2

SQLObject

SQLObject is a Python object-relational mapping (ORM) library for working with relational databases through Python objects.

Source 1

Tortoise ORM

Tortoise ORM is a lightweight, async-native ORM for Python with a Django-inspired API. It supports models, relationships, queries, transactions, and migrations across several database backends.

Free · Apache-2.0 · 5,647 GitHub stars · updated 2026-11-09
