Best Infrastructure as code tools

Researched from live sources on 2026-11-10.

Terraform is the best general fit for building, changing, and versioning infrastructure across many kinds of services. Choose OpenTofu instead if you want a free, open-source tool for managing cloud and on-premises resources.

Terraform

Terraform is an infrastructure-as-code tool for building, changing, and versioning infrastructure using configuration files. It manages infrastructure ranging from compute, storage, and networking to DNS entries and SaaS features.

50,186 GitHub stars · updated 2026-11-09

Pulumi

Pulumi is an open-source infrastructure-as-code platform for building and managing cloud infrastructure using programming languages or configuration languages. It also offers cloud management, governance, secrets, and automation capabilities.

Freemium · Apache-2.0 · 25,855 GitHub stars · updated 2026-11-09

Website · GitHub · Source 1 · Source 2 · Source 3

OpenTofu

OpenTofu is an infrastructure-as-code tool for defining, provisioning, and managing cloud and on-premises resources using human-readable configuration files. It uses providers to interact with cloud platforms and other services through their APIs.

Free · MPL-2.0 · 30,776 GitHub stars · updated 2026-11-10

Website · GitHub · Source 1 · Source 2 · Source 3

AWS CloudFormation

AWS CloudFormation is an infrastructure-as-code service for modeling, provisioning, and managing AWS and third-party resources. It supports deploying infrastructure templates and automating resource management across AWS accounts and regions.

Website · Source 1 · Source 2

AWS Cloud Development Kit

AWS Cloud Development Kit (AWS CDK) is an open-source framework for defining cloud infrastructure in code and provisioning it through AWS CloudFormation. It provides reusable constructs and tools for synthesizing and deploying CDK applications.

Free · Open source

Website · Source 1 · Source 2

Azure Resource Manager

Azure Resource Manager (ARM) is Azure’s infrastructure-as-code service for deploying and managing Azure resources. It orchestrates deployments of dependent resources, and supports templates authored with Bicep or JSON.
